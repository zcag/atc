atc park -h the one help template
❯ atc park -h
atc park: put a session away until it is needed again.

Usage
  atc park <session>... [flags]

Flags
  --all         park every ended session in the bay
  --bay NAME    the bay to look in (default: this folder's)
  --json        print what was parked as JSON
  -h, --help    show this help

Examples
  atc park 7
  atc park "Fix flaky upload test"
  atc park --all --bay api

<session> is a number from atc ls, a title or an id.
