Direction: finish the instrument

atc already has a point of view, chosen in November: an instrument, not an app. Grey paper, Recursive, colour only for state, amber only for "needs you", dense rows, keyboard first. It is right, and this revamp keeps it. What went wrong since is drift: two type scales, eighteen button classes, the phone growing its own rounded look, hints that point at the wrong key, the same thing said five ways. So the direction is not a new look; it is one grammar, applied everywhere including the TUI, the CLI and the Android shell, and then a pass on each screen to remove what does not earn its place.

Layout

  • Three bands on desk: bay bar 40, body, console 32. Every screen lives inside them, Settings and Login included.
  • Every pane has the same header: one 44px line, title left, actions right, pane toggles as icons in the pane they toggle.
  • Phone is the desk folded to one column (your call, Nov 21): same components, same tabs, only the CSS differs.

Type

  • Recursive for the interface, its mono cut only for data (paths, counts, keys, clocks). The reading face for what agents say, as today.
  • Eight sizes by role: 11 12 13 14 16 17.5 22 30. Nothing else.
  • Sentence case everywhere; no uppercase labels (the "PARKED" divider goes).

Colour

  • Amber: needs you, the only fill. Steel: working, always with motion or a bar. Red: failed. Nothing else is coloured.
  • Links are ink with an underline, never steel.
  • Identity (bays, agents) is a 3px tick in a hue from one recipe, never a fill.
  • Dark mode chrome sits a step above the canvas, not below.

Density and shape

  • Two lines per list row; a third only when it needs you.
  • Radii 4 / 7 / 10 (tag, control, sheet), pills only for counts and answer chips. Same as Wisp.
  • 28px controls on desk, 44px targets on phone.

Motion

  • 120ms, one ease, only in answer to an action. The working pulse is the one ambient motion.
  • No entrance animations. Scroll keeps your place; nothing jumps when data arrives.

Icons and keys

  • One 16px set at 1.5 stroke; no Unicode glyphs as icons.
  • Key hints from one table, so they cannot lie. Chips only where the key is the label (quick keys, answer numbers).

Copy voice

  • Plain, short, the interface talking, not a person. "Couldn't" not "Could not". "…" the character.
  • Empty: what is empty and the one action that fills it. Error: what, why, the one fix.
  • One verb per action, kept through the toast: Park, Parked.

Shared language with Wisp

Wisp is getting the same pass in parallel. They are two apps by one person, used side by side all day; they should feel like siblings, not twins (Wisp is a reader of people, atc an instrument for agents). Share these:

Share outright

  • Recursive Mono for data (Wisp already ships it).
  • Radii 4 / 7 / 10 and the ease cubic-bezier(.2,.7,.2,1) (already identical).
  • The palette: ⌘K / Ctrl K, grouped results, Enter opens, Tab previews, Esc closes.
  • The keys overlay on ?, generated from a key table.
  • Toast: atc's ink toast, what happened + one action, bottom centre, 6s (8s with Undo, on z). Wisp's pass picked the same.
  • Keycaps and shortcut words: ? keys, Ctrl K and / the palette, j k move.
  • The greys: Wisp moves its neutrals onto atc's OKLCH slate ramp (hue 250), and its "waits on you" onto atc's amber.
  • The offline line: "Offline since 15:41. Showing what was there. Retry."
  • Times: age, clock, stamp, duration in the four forms on the Times item.

Align names, keep values

  • Token names for the same roles: atc --dim / Wisp --muted; atc --fail / Wisp --bad. Pick one name per role so pages and agents can target both.
  • A row's anatomy: title, one line of preview, meta right (age on top, a mark under it).
  • Empty and error copy rules.

Keep different

  • Body face: Wisp's Geist reads messages; atc's Recursive is an instrument.
  • Accent: Wisp has a brand accent (teal); atc has none, only state colours.
  • Density: atc stays denser.
